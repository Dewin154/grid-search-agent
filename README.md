# Grid Agent Pathfinding
![GitHub release (latest by date)](https://img.shields.io/github/v/release/Dewin154/grid-search-agent?label=Version&color=green)

A Python simulation where an intelligent agent finds the shortest path from start to goal through a randomly generated grid using various search algorithms. This tool serves demonstration/teaching/learning purposes.

## Currently implemented:
- Breadth-First-Search Algorithm
- Depth-First-Search Algorithm
- Search Animation
- Reconstruction of shortest Path
- Animation speed adjustability

## Download
You don't need Python installed to try this out!

👉 **[Download the latest executable here](https://github.com/Dewin154/grid-search-agent/releases/latest)**

Simply download the `.exe` and run.
